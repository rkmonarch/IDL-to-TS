# Solana IDL to TypeScript Converter

A modern, user-friendly tool for converting Solana IDL JSON files to TypeScript functions with proper typings.

[![Solana IDL to TypeScript Converter](https://img.youtube.com/vi/NDu_O3fbJn8/maxresdefault.jpg)](https://www.youtube.com/watch?v=NDu_O3fbJn8)

## 🚀 Features

- **Instant Conversion**: Upload an IDL JSON file and get TypeScript code instantly
- **Type Safety**: Generates fully type-safe TypeScript interfaces and functions
- **Instruction Serialization**: Creates proper serialization code for all instruction arguments
- **Account Interfaces**: Builds TypeScript interfaces for all account structures
- **Custom Types**: Generates TypeScript definitions for custom types defined in the IDL
- **Side-by-Side View**: Compare your IDL and generated TypeScript code in a clean interface
- **Copy & Download**: Easily copy to clipboard or download the generated code

## 📋 How It Works

1. **Upload** your Solana program's IDL JSON file
2. **Review** the generated TypeScript code side-by-side with the IDL
3. **Copy or Download** the TypeScript code for use in your project

## 🛠️ Installation

### Prerequisites

- Node.js 16.x or higher
- npm or yarn

### Setup

```bash
# Clone the repository
git clone https://github.com/rkmonarch/IDL-to-TS.git

# Navigate to the project
cd IDL-to-TS

# Install dependencies
npm install
# or
yarn

# Start the development server
npm run dev
# or
yarn dev
```

Visit `http://localhost:3000` in your browser to use the tool.

## 🔧 Usage

### Basic Usage

1. Click the "Upload IDL" button and select your JSON file
2. The tool automatically converts the IDL to TypeScript
3. Use the "Copy" button to copy the generated code to your clipboard
4. Or use the "Download TypeScript" button to download the generated code as a `.ts` file

### Generated Code Structure

The TypeScript code generated by this tool includes:

- **Interfaces** for all account structures
- **Type definitions** for custom types
- **Instruction builder functions** that create `TransactionInstruction` objects
- **Serialization logic** for all instruction arguments

### Example Generated Function

```typescript
/**
 * Creates an instruction to call initializeUser
 */
export function createInitializeUserInstruction(
  accounts: InitializeUserAccounts,
  programId: PublicKey = PROGRAM_ID
): TransactionInstruction {
  const keys = [
    { pubkey: accounts.payer, isSigner: true, isWritable: true },
    { pubkey: accounts.user, isSigner: false, isWritable: false },
    { pubkey: accounts.userStats, isSigner: false, isWritable: true },
    { pubkey: accounts.systemProgram, isSigner: false, isWritable: false },
    { pubkey: accounts.rent, isSigner: false, isWritable: false },
  ];

  // Instruction discriminator
  const discriminator = Buffer.from([183, 18, 70, 156, 148, 109, 161, 34]);
  const data = discriminator;
  
  return new TransactionInstruction({
    keys,
    programId,
    data
  });
}
```

## 🌟 Benefits Over Manual Implementation

1. **Saves Development Time**: Automates the tedious process of creating instruction builders
2. **Reduces Errors**: Ensures correct serialization and account structure
3. **Easier Program Updates**: When your program changes, regenerate the code from the updated IDL
4. **No Framework Lock-In**: Generated functions don't depend on Anchor or other frameworks
